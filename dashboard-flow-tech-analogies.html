How Dashboard OS Works

A guide to the natural language parsing, state engine, and commit pipeline explained through computer science analogies.

1. The AI Parser as a Compiler Text ➔ AST

In traditional coding, you write human-readable language (like TypeScript) and compile/interpret it. The compiler parses the characters, matches keywords, and outputs an Abstract Syntax Tree (AST)—a highly structured tree representation of your program.

Our AI Parser (lib/parse.ts) is literally a Compiler for natural language. It takes a raw, unstructured string of human speech (e.g., "chicken rice $8 lunch") and runs it through an LLM engine with tool-calling declarations. The compiler identifies arguments and yields a structured JSON action—our AST.

Smart Macro Compilation
If you omit nutrition fields (e.g., you type "ate two eggs"), the compiler triggers a built-in macro-estimation routine to approximate the missing properties, setting an estimated: true flag. If you explicitly state values (e.g., "350 cal"), it maps them directly and leaves estimated: false.

2. The Action Handler as a Network Router Route ➔ Save

In data networks, a router or switch receives packets, looks at their header (metadata like protocol and destination IP), and directs them to the correct local port or server.

Our Action Handler (lib/actions.ts) is a Network Router. It takes the parsed AST packet and checks the header type value. It then routes the cargo directly to specific database functions.

Data Validation & Sanitization
Just as a network router drops malformed packets or modifies routing headers, the Action Handler sanitizes inputs. For example, it checks if categories match allowed values, maps descriptions to categories (e.g. "coffee" maps to "Food"), and enforces database consistency before persistence.

export async function applyParsedAction(action: ParsedAction, date: string) {

3. Telegram Flow as a Git Commit Pipeline Interactive Simulator

When interacting with the system via Telegram, we don't write data directly. Instead, we use a Staging Area—just like Git!

Git Stage (git add) Typing a message creates a temporary draft state (stored with a 15-minute TTL) awaiting your review.
Git Amend (git commit --amend) Sending a correction (e.g. "make that $15") patches fields in the active draft while preserving everything else.
Git Push (git push) Replying "yes" or confirming locks in the changes and commits them permanently to the database.
