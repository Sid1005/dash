# Dash

A personal mission control dashboard built with Next.js and Supabase.

## Features

- Cockpit: Overview of daily metrics and tasks.
- Activities: Log and track daily activity.
- Calendar: Day planner and timeblock grid.
- Life's Work: Goal planning and markdown-based editor.
- Scratchpad: Notebook for quick notes.
- Tasks & Learning: Manage to-dos and learning milestones.
- Workouts: Log and track exercise sessions.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env.local` based on `.env.example`.

3. Run the development server:
   ```bash
   npm run dev
   ```
